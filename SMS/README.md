# Student Management System

A full-stack Student Management System built with React, FastAPI, SQLAlchemy, and SQLite.

The system provides separate Student and Admin functionality with authentication, student management, courses, results, attendance, and profile management.

##  Features

### Student Portal

- Student Registration
- Student Login
- JWT Authentication
- Student Dashboard
- View Profile
- Edit Profile
- View Courses
- View Results
- View Attendance
- Logout

### Admin Portal

- Admin Login
- Admin Dashboard
- Manage Students
- Add, Edit and Delete Students
- Manage Courses
- Add, Edit and Delete Courses
- Manage Results
- Add, Edit and Delete Results
- Manage Attendance
- Mark and Manage Student Attendance

##  Technologies Used

### Frontend
